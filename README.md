# Тибет. Путь к Кайласу

Русский лендинг паломничества 12–30 августа 2027 с Леонидом Кутузовым, Ксенией Абрамовой и Андреем Барановым.

## Файлы

- `dist/index.html` — весь контент страницы и программа по дням.
- `dist/styles.css` — оформление, адаптация к телефону и большому экрану.
- `dist/script.js` — раскрытие и сворачивание программы.
- `dist/assets/` — фотографии, предоставленные организатором, портреты Леонида с Neuro-Universe, Ксении с Eversummit Club и Андрея из его ранее опубликованной программы.

Сайт статический: не требует сборки, базы данных и серверного приложения. Контактные кнопки открывают `https://t.me/vsemaya`. Шрифт Golos Text загружается из Google Fonts; при отсутствии сети используется системный шрифт.

## Предпросмотр

Из папки проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Открыть `http://localhost:4173`.

## Перенос на GitHub и хостинг

Для размещения нужен каталог `dist` целиком. Все локальные ссылки относительные; страница подходит для GitHub Pages и обычного статического хостинга. Секретов и ключей в исходниках нет. GitHub-репозиторий и собственный домен пока не созданы и не подключены.

## Перед открытием продаж

1. Сверить список включённых услуг с поставщиками поездки 2027 года: он адаптирован из ранее опубликованной программы Андрея.
2. Согласовать 18 дней программы с датами 12–30 августа (19 календарных дней). Дополнительный день не придуман.
3. Подтвердить расписание и места на перелёт Али Пуранг → Лхаса в августе 2027, а также условия отмены позднее чем за два месяца.

Подтверждённые условия: 3 900 € для первых пяти участников, затем 4 500 €; предоплата 2 000 €, остаток на месте; 100% возврат предоплаты при отказе не позднее чем за два месяца до начала.

Дополнения по сообщению организатора: возвращение самолётом через Али Пуранг +500 €; одноместное размещение +500 €. Развилка следует после завершения коры в день 14. В авиаварианте ночь в Дарчене, перелёт в Лхасу на день 15, свободный день в городе на день 16 и вылет на день 17. Это на один программный день короче наземного варианта и сокращает длинные обратные переезды. До продажи опции нужно подтвердить расписание и доступность мест для группы.
